
# Python IP Checker

A simple Python script to check if an IP address is valid.

My first Python project, built while learning programming and networking.

## Features

- Validates IPv4 and IPv6 addresses
- Identifies the IP version
- Checks if an IP is globally reachable
- Handles invalid inputs

## How to use

Run the script from your terminal:

```bash
python ip_checker.py
```

Example:

```text
Inserisci un indirizzo IP: xxx.xxx.xx
IP valido!
Versione: IPv4
Indirizzo globale: False
```

## Built with

Python 3 — using the built-in `ipaddress` module.
